# Читалка вслух

Читалка книг (txt, fb2, epub, pdf, docx, zip) с чтением вслух, регулировкой скорости, поиском и оглавлением. Устанавливается на телефон как приложение (PWA) и работает без интернета.

## Как выложить на GitHub Pages

1. Создайте новый публичный репозиторий, например `chitalka`.
2. Нажмите **Add file → Upload files** и перетащите **содержимое** этой папки (index.html, sw.js, manifest.webmanifest, .nojekyll, папки lib и icons), а не саму папку.
3. Откройте **Settings → Pages**, в разделе **Branch** выберите `main` и `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/chitalka/`.

## Как установить на телефон

- **Android (Chrome):** откройте ссылку, затем меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
- **iPhone (Safari):** кнопка «Поделиться» → **На экран «Домой»**.

## Как обновить

Замените файлы в репозитории и поменяйте номер в первой строке `sw.js` (`chitalka-v1` → `chitalka-v2`). Иначе телефон может показывать старую версию.
